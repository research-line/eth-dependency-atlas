# Contributing

Corrections are the most valuable contribution.

- **Correction of an entry:** Open an issue with the *Correction* template. Give the entry id (e.g. `COL-0005`, `RES-0003`, or the `atlas_id`), the exact statement (theorem/page) and the reason: wrong class, missing rescue, wrong size measure, or a full-text detail.
- **New collision or rescue:** Same template. Please include the encoding argument (for a collision) or the reference that proves the result from a non-refuted hypothesis (for a rescue).
- **Status of the refutations:** If an independent verification or a retraction appears, please open an issue. All classes are conditional on the refutations (A0).

Entries change only through versioned commits with the reason in the changelog.
